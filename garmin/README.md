# אפליקציית רשימת קניות לשעון Garmin (Connect IQ)

אפליקציה ייעודית לשעוני **Garmin Forerunner (AMOLED)** המאפשרת צפייה ברשימת הקניות וסימון פריטים בזמן אמת בסופרמרקט ישירות מפרק כף היד.

---

## 📱 תכונות האפליקציה בשעון
* **התאמה מלאה למסך AMOLED:** רקע שחור עמוק (`COLOR_BLACK`), טקסט לבן קריא וניגודיות גבוהה.
* **צפיפות אופטימלית:** בין 4 ל-6 פריטים במסך בו-זמנית עם ריווח מדויק וברור.
* **סימון פריט בקו חוצה:** ללא תיבות סימון (צ'קבוקס) – לחיצה על פריט מעבירה עליו קו חוצה (Strikethrough) ומעמעמת אותו.
* **תמיכה מלאה בעברית:** עיבוד והיפוך טקסט (RTL Bidi Shaping) לתצוגה ישרה, קריאה וטבעית.
* **שליטה כפולה (מגע + כפתורים פיזיים):**
  * **מגע:** גלילה עם האצבע והקשה (Tap) על פריט לסימונו (כולל רטט אישור עדין).
  * **כפתורים פיזיים:**
    * כפתורי `UP` / `DOWN`: גלילה והזזת סמן הבחירה.
    * כפתור `START` / `ENTER`: סימון/ביטול סימון של הפריט הנבחר.
    * לחיצה ארוכה על `MENU`: רענון מיידי מהשרת.
* **תמיכה ב-Offline:** שמירת הרשימה בזיכרון המקומי של השעון (`Storage`), כך שגם אם נכנסים לסופרמרקט ללא קליטה סלולרית הרשימה זמינה מיידית.

---

## 🛠️ מדריך הרצה וסימולציה מ-VS Code / מחשב

### שלב 1: התקנת סביבת Connect IQ ב-VS Code
1. פתח את **VS Code**.
2. גש ללשונית ה-Extensions (`Ctrl + Shift + X`), חפש והתקן את ההרחבה:
   **Monkey C** (של Garmin).
3. פתח את שורת הפקודות ב-VS Code (`Ctrl + Shift + P`) והקלד:
   `Monkey C: Download Connect IQ SDK`
   * בחר בגרסת ה-SDK העדכנית ביותר (מומלץ System 7 / SDK 7.x).
4. צור מפתח מפתח (Developer Key) פעם אחת:
   * הקלד ב-`Ctrl + Shift + P`: `Monkey C: Generate a Developer Key`
   * בחר לשמור את הקובץ בשם `developer_key.der` (למשל בתיקיית הבית שלך).

### שלב 2: פתיחת פרויקט ה-Garmin
1. ב-VS Code, פתח את התיקייה `garmin/`.
2. ודא שהמכשיר הנבחר הוא דגם ה-AMOLED שלך (`fr965` המייצג את סדרת Forerunner AMOLED).

### שלב 3: הרצת הסימולטור (Garmin Simulator)
1. לחץ על מקש **`F5`** (או בחר בתפריט `Run -> Start Debugging`).
2. חלון הסימולטור של Garmin ייפתח על המסך ויציג את שעון ה-Forerunner.
3. **בדיקת מגע:** הקלק וגרור עם העכבר על מסך השעון כדי לגלול, והקלק על שורה כדי לראות את הקו החוצה מופיע עם עדכון הספירה למעלה.
4. **בדיקת כפתורים:** לחץ על הכפתורים הפיזיים במסגרת השעון (UP, DOWN, START).
5. **הגדרת כתובת השרת בסימולטור:**
   * בתפריט הסימולטור בחר: `File -> Edit Persistent Storage -> Edit Application.PropertiesData` (או דרך `Settings`).
   * הזן את הכתובת של ה-Tailscale Funnel שלך (למשל: `https://your-node.your-tailnet.ts.net/grocery_list`).

## 🌐 חיבור דרך Tailscale Funnel בתת-נתיב `/grocery_list`

מכיוון שבפורט `443` רץ שירות אחר, אנו מנתבים את תת-הנתיב `/grocery_list` מבלי לגעת בנתיב הראשי:

בשרת שלך (10.0.50.10) הרץ בטרמינל פעם אחת:
```bash
tailscale serve --bg --set-path /grocery_list http://127.0.0.1:8888
tailscale funnel --bg --set-path /grocery_list on
```

בדיקת תקינות מהדפדפן או מהטלפון:
`https://zaarur-server.tiffany-minor.ts.net/grocery_list`

## 📦 התקנה על השעון הפיזי

1. ב-VS Code הקש `Ctrl + Shift + P` ובחר:
   `Monkey C: Export Project by Device`
2. בחר ב-`fr965` ובחר תיקיית יעד לשמירת קובץ ה-`.prg`.
3. חבר את שעון ה-Garmin למחשב באמצעות כבל ה-USB המקורי.
4. השעון יופיע ככונן חיצוני במחשב. העתק את קובץ ה-`.prg` ישירות לתוך התיקייה:
   `GARMIN/APPS/`
5. נתק את השעון – האפליקציה "רשימת קניות" תופיע ברשימת האפליקציות והפעילויות שלך!
