# 🛒 אפליקציית רשימת קניות חכמה (Smart Grocery List)

אפליקציית רשימת קניות מודרנית בקונטיינר Docker, מותאמת לנייד, בעברית מלאה (RTL), עם מנוע סיווג חכם שלומד משימוש קודם, אינטגרציה עם Google Gemini API, ובוט טלגרם מובנה.

---

## ✨ תכונות עיקריות

- 📱 **עיצוב מותאם לנייד (RTL)** — עיצוב נקי ומוקפד בדיוק לפי המפרט, ללא הסחות דעת.
- 🧠 **אלגוריתם סיווג ולמידה מקומי חכם**:
  - נירמול עברי מתקדם (התאמה בין כתיב חסר למלא, למשל `עגבניה` ↔ `עגבנייה`, יחיד/רבים, קידומות).
  - שמירה ב-Cache מקומי עם ציון התאמה (Confidence).
  - אם ההתאמה ≥ 99% — הסיווג מתבצע מקומית ב-0 עלות וללא קריאה ל-API.
  - אם אינו בטוח ב-99% — פונה ל-Gemini API ושומר את התוצאה ללמידה עתידית.
  - תיקון קטגוריה ידני על ידי המשתמש מקבל 100% ביטחון ומלמד את המערכת לצמיתות.
- 💬 **שיחה ופקודות דינמיות לחלוטין**:
  - מזהה פקודות שיחה מורכבות בעברית (למשל: "אם יש מלפפון תוסיף 3 אם אין אז תשים 9", "תמחק כל מה שמתחיל ב-א'", "תוריד את הביצים").
  - פועל בסינכרון מלא עם כל מצב הרשימה הקיים.
- 🤖 **ניהול מודלים דינמי ב-Gemini**:
  - בהזנת מפתח API — סורק את המודלים הפעילים, בודק תגובה אמיתית, מדרג לפי מהירות ועלות (Flash לפני Pro).
  - מנגנון Fallback אוטומטי למודל הבא אם מודל מחזיר שגיאה.
  - רשימת מודלים ממוזערת בהגדרות.
- 📬 **בוט טלגרם (Long Polling)**:
  - פועל ב-Long Polling חסכוני (`timeout=30`), ללא עומס וללא צורך בכתובת ציבורית/HTTPS.
  - תמיכה ב-2 מזהי Chat ID מורשים.
  - פקודת `/start` שולחת הודעת תקינות, וכל הודעת טקסט מעובדת ישירות ברשימה.
- ↕️ **סדר פריטים מדויק**:
  - פריטים לא מסומנים: ממוינים לפי סדר הוספתם (`global_add_order`).
  - פריט שמסומן: עובר לתחתית הקטגוריה.
  - בתוך המסומנים: הפריט שסומן אחרון מופיע ראשון בין המסומנים, והראשון שסומן מופיע בתחתית.
- 👆 **עריכה והוספה ידנית**:
  - לחיצה ארוכה (Long Press) על פריט פותחת חלון עריכה מלא (שם, כמות, יחידה, הערה, קטגוריה).
  - הוספה ידנית עם כפתור `+`.
- ⚙️ **ניהול קטגוריות**:
  - הוספה, מחיקה ושינוי סדר תצוגה באמצעות חצים למעלה/למטה.

## 🚀 הרצה עם Docker Compose

```bash
# הרצה ברקע
docker compose up --build -d
```

לאחר ההרצה:
- **ממשק משתמש (Frontend)**: [http://localhost:8888](http://localhost:8888) (פורט 8888)
- **שרת Backend ו-API**: [http://localhost:8000](http://localhost:8000) (פורט 8000)
- **מסמכי API (Swagger)**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **נתונים**: נשמרים בתיקיית `./data/grocery.db` (SQLite Volume מקומי).

---

## 🛠️ הרצה לפיתוח מקומי (ללא Docker)

### Backend
```bash
cd backend
python -m venv .venv
.\.venv\Scripts\activate      # Windows
pip install -r requirements.txt
python -m uvicorn main:app --reload --port 8000
```

### Frontend
```bash
cd frontend
npm install --legacy-peer-deps
npm run dev
```
